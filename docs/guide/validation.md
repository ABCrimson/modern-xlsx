# Validation issue categories

`Workbook#validate()` returns a `ValidationReport` whose `issues` each carry a `severity` (`error`, `warning` or `info`) and a `category`. `Workbook#repair()` returns a repaired copy with the repairable issues fixed, and leaves the workbook it was called on unchanged. The [package README](../../packages/modern-xlsx/README.md#validation-and-repair) shows both calls; this page lists what each category detects.

Each issue has a `category` (`IssueCategory`):

| Category                | Detects                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `cellReference`         | Cell references that do not parse.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `styleIndex`            | Cell style indices past the cellXfs list; cellXf font, fill and border ids past their lists; a custom `numFmtId` without its record; no font or no cellXf; conditional-format and table `dxfId`s past the dxf list; a font, fill, border or differential-format colour that is not 6 or 8 hex digits (all `error`s); fewer than two fills (a `warning`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `mergeCell`             | Merge ranges that do not parse or overlap (`error`s), or are reversed (a `warning`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `sharedString`          | Shared-string cells without a value.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `sheetName`             | Empty, too long (over 31 characters), forbidden or control characters, a leading or trailing apostrophe, the reserved name `History`, duplicates.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `definedName`           | A defined name with an empty name (an `error`) or an empty value (a `warning`); a `_xlnm.Print_Area` or `_xlnm.Print_Titles` name, in any letter case, whose value has an area without a sheet qualifier, which Excel refuses (an `error`); a defined name Excel refuses to open, other than an `_xlnm.` name: an R1C1 reference or a name that starts with one, `TRUE` or `FALSE`, a character Excel refuses, a leading digit, `.` or `?`, or more than 255 characters (an `error`).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `dataValidation`        | Data validations with an empty `sqref`, or a list without `formula1` (`warning`s).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `conditionalFormatting` | A rule with more than three formulas, and a colour-scale or data-bar colour that is not 6 or 8 hex digits (both `error`s). A dangling conditional-format `dxfId` is reported as `styleIndex`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `theme`                 | No theme colours (an `info` issue).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `metadata`              | Document property dates (`created`, `modified`) that are not W3CDTF (a `warning`), and whitespace-only text properties (an `info` issue).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `structure`             | A workbook without sheets; a tab, sparkline or rich-text run colour that is not 6 or 8 hex digits; two series of a chart written from its model that share an `order`; a threaded comment `id`, `personId` or `parentId`, or a person `id`, that is not a GUID in braces, a reply whose `parentId` names another reply, a second thread root on a cell, and a threaded comment text longer than 32,767 UTF-16 code units; a table name `addTable` refuses (Excel's naming rules, or a name another table or a defined name already has), a `calculatedColumnFormula` or `totalsRowFormula` that holds the `@` this-row shorthand (`[@Qty]`), which Excel refuses in a table definition, and a table totals-row cell Excel refuses, such as a formula other than the column's `SUBTOTAL` (all `error`s). Row indices that are not strictly ascending, a pivot table whose `cacheId` names no pivot cache, and the first pivot table whose write would fail with `SIZE_LIMIT` over the items and pivot fields the writer adds to it (`warning`s). |
| `sheetProtection`       | A sheet protection `password` that is not the 1 to 4 hex digit legacy hash a file stores (an `error`); set `plainPassword` to protect with a password.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |

The report stores the issues found first, at most 10,000 of them and at most 16 MiB of message and location text, whatever the workbook holds. `errorCount`, `warningCount`, `infoCount` and `isValid` count every issue, and `omittedIssueCount` says how many were left out (absent when none).
