Features

What the library reads and writes, all under the MIT license.

Cell styling

Fonts, fills, borders, alignment, text rotation, shrink-to-fit. Fluent builder API produces style indices for any cell.

Number formats

Built-in Excel format codes plus custom formats. formatCell() turns a value and a format code into display text for dates, currency, percentages and scientific notation.

Data validation

List, whole number, decimal, date, time, text length and custom formula rules, with input prompts and error messages.

Conditional formatting

Color scales, data bars, icon sets and formula-based rules, read and written.

Charts

Ten chart types (bar, column, line, pie, doughnut, scatter, area, radar, bubble and stock) built with the fluent ChartBuilder. Other chart XML is kept verbatim.

Images and barcodes

addImage embeds PNG, JPEG and GIF images; addBarcode draws QR, Code 128, EAN-13, UPC-A, Code 39, ITF-14 and GS1-128 symbols into the sheet.

Pivot tables

Read and write pivot tables. PivotTableBuilder builds the definition; Excel computes the table's values when it opens the file.

Formula engine

Evaluate formulas in memory with 54 built-in Excel functions, following Excel's semantics for type coercion, error propagation and operators.

Streaming writer

StreamingXlsxWriter writes rows one at a time without building a Workbook first. It holds the compressed output in memory until finish() returns it.

Frozen panes

Freeze rows, columns or both with frozenPane, or set split panes with splitPane.

Hyperlinks

Internal sheet links, external URLs and mailto links, with display text and tooltips.

Comments and notes

Add, read and remove cell comments with an author. Threaded comments are read and written too.

Sheet protection

Protect a worksheet through its sheetProtection settings, and lock the workbook structure or windows through Workbook.protection.

Encryption

Open and save password-protected .xlsx files (full build). Writes ECMA-376 Agile Encryption with AES-256, SHA-512 and 100,000 spin rounds; reads Agile and Standard Encryption.

Page setup

Paper size, orientation, print scale, margins, headers and footers, and page breaks.

Dates and Temporal

dateToSerial() takes a Date or a TemporalLike: a Temporal.PlainDate, a Temporal.PlainDateTime or any object with year, month and day. serialToDate() returns a Date.

Rust and WebAssembly core

The Rust core, compiled to WebAssembly, does the ZIP compression and decompression and the SAX-style XML parsing. The modern-xlsx/lite build leaves encryption out for a smaller binary.

Tree-shakable ESM

The modern-xlsx and modern-xlsx/lite entries are ES modules with "sideEffects": false and no runtime dependencies, so bundlers can drop unused JavaScript exports. The WASM binary is loaded whole.

Quick start

Create a styled spreadsheet, save it and read it back in Node.js.

example.mjs (Node) 
import { initWasm, Workbook, readFile } from 'modern-xlsx';

await initWasm();

// Create a new workbook
const wb = new Workbook();
const ws = wb.addSheet('Sales');

ws.cell('A1').value = 'Product';
ws.cell('B1').value = 'Revenue';
ws.cell('A2').value = 'Widget';
ws.cell('B2').value = 9999.99;

// Style headers
const header = wb.createStyle()
  .font({ bold: true, size: 14, color: '1F4E79' })
  .fill({ pattern: 'solid', fgColor: 'D6E4F0' })
  .alignment({ horizontal: 'center' })
  .build(wb.styles);

ws.cell('A1').styleIndex = header;
ws.cell('B1').styleIndex = header;

// Currency format
const currency = wb.createStyle()
  .numberFormat('$#,##0.00')
  .build(wb.styles);
ws.cell('B2').styleIndex = currency;

await wb.toFile('sales.xlsx');

// Read the file back
const saved = await readFile('sales.xlsx');
console.log(saved.getSheet('Sales')?.cell('A1').value); // 'Product'

Architecture

A TypeScript API over a Rust core compiled to WebAssembly.

Workbook data crosses the WASM boundary as JSON strings. The Rust core handles ZIP compression and decompression, SAX-style XML parsing and the shared string table (SST). On write it collects every shared-string cell into the SST first, then replaces each one's text with its SST index while it writes each sheet's XML, without cloning the worksheet. Inline-string cells stay inline.
